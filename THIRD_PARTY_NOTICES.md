## Olympus / Evident VSI and Bio-Formats support

- **BioIO** — see the upstream BioIO project license
- **bioio-bioformats** — MIT package; uses the Bio-Formats Java stack
- **bffile** — Bio-Formats bridge used by the BioIO plugin; see upstream license
- **scyjava** — see upstream license
- **cjdk** — see upstream license
- **JPype / JPype1** and **jgo** — see upstream license files
- **ome-types**, **xsdata**, **dask**, **xarray**, **fsspec**, and transitive dependencies — see their upstream license files
- **Bio-Formats** — multiple components/licenses; consult the upstream Bio-Formats notices when redistributing or provisioning its runtime components.

PathoImage Toolkit does not bundle a JDK in the repository release files generated by the provided build configuration. On first VSI use, scyjava/cjdk may download a compatible Zulu JDK and Bio-Formats/Maven artifacts into the user's local cache. Those downloaded components remain subject to their respective upstream licenses.
